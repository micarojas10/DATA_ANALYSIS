# Curso de Data Analytics

¡Bienvenido/a a mi repositorio de aprendizaje de Data Analytics!

Este espacio recoge los ejercicios y proyectos prácticos que voy desarrollando durante mi formación en análisis de datos.

El objetivo de este repositorio es documentar mi evolución, poner en práctica los conocimientos adquiridos y construir una base sólida en las distintas herramientas y tecnologías utilizadas en el ámbito del análisis de datos.

## Contenido del repositorio

Actualmente, el repositorio está organizado en dos áreas:

### SQL
Ejercicios prácticos del Nivel 1, utilizando SQL y MySQL Workbench para trabajar con bases de datos, consultas, manipulación de datos y modelado de estructuras relacionales.

### Python
Carpeta preparada para incorporar los ejercicios y proyectos de Python en una fase posterior de la formación.
